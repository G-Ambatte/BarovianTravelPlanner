# Barovian Travel Planner

The Barovian Travel Planner is a small project to help calculate distances and travel times within the valley kingdom of Barovia.

## ...why?

Many Dungeon Masters feel the need to modify the scale of Barovia, and even the canon size of the country has changed between editions! In order to help Dungeon Masters get a feel for the size of the place, I created this tool, with sliders to adjust map scale and party travel speed.

### Map Scale

The default map scale is 1 hex = 1/4 mile, as stated in the bottom left corner of the map.

This is currently also the minimum value of map scale - normally, Dungeon Masters want to go bigger, not smaller! The current maximum value for map scale is 10 miles per hex.

### Travel Speed

The default travel speed is set to 3 mph, which is the "Normal" travel speed in the Basic Rules. The current minimum on the speed slider is 1 mph, and the maximum is 25 mph - I believe some flying mounts can move at up to 20 mph - at the default scale, this would allow a flying rider to cross the entire country in under an hour!
